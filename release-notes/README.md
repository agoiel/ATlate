# Что нового — описания релизов

Один файл на версию: `v0.6.7.md` и т. д. Внутри — только список изменений (Markdown),
без заголовка и без инструкции по установке: их добавит `.github/scripts/release_notes.py`.

- **Новый релиз.** Положите файл в репозиторий до публикации релиза — описание соберётся само
  (`release.yml`): «Что нового в 0.6.7», затем инструкция по установке.
- **Уже вышедший релиз.** Измените или добавьте файл в `main` — описание релиза обновится
  (`release-notes.yml`, можно запустить и вручную во вкладке Actions).

Перед публикацией поднимите номер версии в `desktop/app/__init__.py` и `android/app/build.gradle.kts`
(`versionName`, а `versionCode` — на единицу). Если номер не совпадает с тегом, сборка релиза
остановится (`.github/scripts/check_version.py`).
