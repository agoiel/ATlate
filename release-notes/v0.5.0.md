- **Параллельное распознавание** (ПК и Android):
  - проходы распознавания идут одновременно — заметно быстрее на многоядерных процессорах;
  - включено по умолчанию, выключается в карточке «Для разработчиков»;
  - одновременно не больше трёх проходов, а в Live — не больше двух, чтобы не грелся телефон;
  - на ПК с EasyOCR проходы по-прежнему идут по очереди.
- **Режим разработчика** — новая карточка «Для разработчиков» в настройках, по умолчанию выключен. Включённый показывает:
  - время каждого этапа: снимок, распознавание, облака, перевод;
  - сколько строк нашёл каждый проход и сколько из них добавили дополнительные проходы;
  - цветные рамки строк поверх страницы, своим цветом для каждого прохода (выключаются отдельно);
  - журнал последних запусков с кнопкой «Копировать журнал».
- Кнопка «Сравнить» распознаёт текущую зону по очереди и параллельно и показывает, что быстрее и совпал ли результат.
